Membuat Web Interaktif dengan JavaScript

JAVASCRIPT Oleh: Tim WebEdu

Kita kembali lagi ke analogi membangun rumah. Jika HTML adalah rangka bangunan dan CSS adalah cat dinding serta dekorasinya, maka JavaScript (JS) adalah instalasi listrik dan saluran airnya. JavaScript adalah bahasa pemrograman yang membuat website menjadi "hidup" dan bisa diajak berinteraksi.

Tanpa JavaScript, website hanya bersifat statis (hanya bisa dibaca). Dengan JavaScript, kamu bisa membuat tombol yang merespon ketika diklik, membuat animasi popup, mengubah tema gelap/terang, hingga mengambil data dari server tanpa perlu me-*refresh* halaman.

1. Cara Memasukkan JavaScript

Sama seperti CSS, kode JavaScript bisa disisipkan langsung ke dalam HTML menggunakan tag <script>. Biasanya, pemanggilan script diletakkan di bagian paling bawah dokumen (tepat sebelum tag penutup </body>) agar tidak menghambat pemuatan elemen visual HTML.

<script>
    // Ini adalah komentar di JavaScript
    alert("Selamat datang di Web Developer!");
</script>

2. Menambahkan Logika Interaktif

Kekuatan utama JavaScript ada pada kemampuannya memanipulasi HTML yang sudah ada di layar (disebut DOM Manipulation). Contoh paling sederhana adalah mendeteksi ketika pengguna mengklik sebuah tombol, lalu melakukan sesuatu setelahnya.

// 1. Cari tombol berdasarkan ID-nya di HTML
const tombol = document.getElementById("tombol-pesan");

// 2. Beri perintah ketika tombol diklik
tombol.addEventListener("click", function() {
    alert("Keren, kamu berhasil mengklik tombol!");
    
    // Ubah warna latar belakang web menjadi hitam
    document.body.style.backgroundColor = "black";
});

Belajar Logika Pemrograman

Berbeda dengan HTML dan CSS, JavaScript adalah bahasa pemrograman yang utuh. Kamu akan mulai belajar konsep logika dasar seperti variabel (menyimpan data), percabangan (if/else), dan perulangan (loop). Fitur "Mode Gelap" yang ada di pojok kanan atas website ini juga sepenuhnya dibuat menggunakan JavaScript murni yang super sederhana!

Selamat, sekarang kamu sudah memahami "Trisula" dasar dalam pembuatan website (HTML, CSS, JS). Kamu sudah siap membangun websitemu sendiri!
