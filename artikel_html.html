Mengenal Struktur Dasar HTML5

HTML DASAR Oleh: Tim WebEdu

HTML (HyperText Markup Language) adalah bahasa standar yang digunakan untuk membuat dan menyusun halaman web. Jika kita analogikan, HTML adalah susunan rangka tulang atau struktur batu bata pada sebuah bangunan. Tanpanya, kita tidak bisa menaruh paragraf, gambar, maupun link di dalam halaman internet.

Dalam perkembangannya, HTML5 menjadi versi terbaru yang membawa banyak pembaruan fitur, terutama dukungan terhadap multimedia (seperti pemutar video dan audio langsung bawaan tanpa memerlukan plugin pihak ketiga).

1. Struktur Dokumen HTML5

Setiap kali kamu membuat dokumen HTML, ada beberapa baris kode wajib yang harus dituliskan paling awal. Struktur dasar ini berfungsi untuk memberitahu browser bahwa file yang dibaca adalah halaman web versi HTML5 yang modern.

<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <title>Judul Web Kamu</title>
</head>
<body>
    <h1>Halo Dunia!</h1>
    <p>Ini adalah paragraf pertama saya.</p>
</body>
</html>

2. Penjelasan Tag-Tag Penting

Berikut adalah arti dan fungsi dari struktur kode di atas agar kamu sangat mudah menjelaskannya saat ditanya dosen/guru pas presentasi tugas nanti:

<!DOCTYPE html>: Adalah deklarasi wajib yang memberi tahu browser bahwa dokumen ini menggunakan standar HTML5 terbaru.

<html>: Merupakan tag induk (parent) pembungkus seluruh konten web. Atribut lang="id" digunakan untuk menandakan bahwa konten web berbahasa Indonesia.

<head>: Adalah area belakang layar. Informasi di sini tidak langsung tampil di halaman web, melainkan berisi konfigurasi seperti judul tab browser (<title>) dan tautan file eksternal CSS/JS.

<body>: Bagian tubuh web. Semua kode yang ditulis di dalam tag ini (seperti tulisan h1, gambar, link) adalah konten nyata yang bisa dilihat langsung oleh pengunjung web.

Kesimpulan

Memahami struktur dasar HTML5 adalah langkah paling krusial sebelum kamu melangkah lebih jauh untuk belajar mempercantik web dengan CSS atau menambahkan interaksi menggunakan JavaScript. Yuk, coba buat file pertamamu sekarang!
