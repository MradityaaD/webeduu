Setup VS Code & DevTools

TOOLS PEMULA Oleh: Tim WebEdu

Seorang tukang kayu membutuhkan palu dan gergaji yang bagus untuk menghasilkan perabotan berkualitas. Begitu pula dengan seorang Web Developer. Sebelum mulai menulis ratusan baris kode HTML, CSS, dan JavaScript, kita membutuhkan alat tempur yang tepat. Alat utama kita adalah Text Editor dan Browser DevTools.

1. Visual Studio Code (VS Code)

VS Code saat ini adalah text editor paling populer di seluruh dunia, dibuat oleh Microsoft dan bisa digunakan secara gratis. Berbeda dengan mengetik di Notepad bawaan komputer, VS Code memiliki fitur Syntax Highlighting (memberi warna berbeda untuk setiap jenis kode), sehingga mata kita tidak mudah lelah dan kode jauh lebih mudah dibaca.

Untuk mempermudah pekerjaan kita, pastikan kamu menginstal beberapa Extension (tambahan fitur) wajib bagi pemula di bawah ini melalui menu Extension di VS Code:

1. Live Server
   (Fungsinya untuk melihat perubahan HTML/CSS secara langsung
    tanpa perlu menekan tombol refresh / F5 berkali-kali di browser).

2. Prettier - Code formatter
   (Fungsinya merapikan jarak baris kode secara otomatis
    ketika kita menekan tombol Save / Ctrl+S).

3. Auto Rename Tag
   (Ketika kita mengubah tag pembuka HTML, tag penutupnya
    akan otomatis ikut berubah).

2. Menguasai Browser DevTools

Alat kedua yang tidak kalah penting sudah terpasang langsung di dalam browsermu (seperti Google Chrome atau Mozilla Edge). Fitur ini bernama Developer Tools (Inspect Element).

Cara membukanya sangat mudah. Saat membuka website apa pun, klik kanan di area kosong, lalu pilih menu "Inspect" (Inspeksi), atau cukup tekan tombol F12 pada keyboard laptopmu.

Dengan DevTools, kita bisa melakukan banyak hal "sakti", seperti:

  • • Menganalisis Error: Jika JavaScript kita tidak berjalan, panel Console akan memberitahu letak baris yang salah.
  • • Eksperimen CSS: Kita bisa iseng mengubah ukuran font atau mengganti warna teks secara langsung dari panel Elements tanpa mengubah kode asli di VS Code.
  • • Uji Responsif: Membantu kita mensimulasikan bagaimana tampilan website kita jika dibuka dari layar Handphone atau Tablet.

Kuasai kedua "senjata" ini, maka perjalanan belajarmu akan menjadi dua kali lebih cepat dan terhindar dari banyak rasa frustrasi akibat kode yang error!
