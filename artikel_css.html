Mempercantik Web dengan CSS

CSS STYLING Oleh: Tim WebEdu

Jika HTML dianalogikan sebagai struktur rangka rumah, maka CSS (Cascading Style Sheets) adalah cat dinding, desain interior, dekorasi, hingga tata letak furnitur di dalamnya. Tanpa CSS, halaman web kita akan terlihat sangat polos, membosankan, dan hanya berupa teks hitam di atas latar belakang putih.

CSS berfungsi untuk memisahkan konten (HTML) dari presentasi visual. Dengan menggunakan file CSS eksternal, kita bisa mengatur warna, jenis font, ukuran teks, bayangan kotak, hingga tata letak responsif pada semua halaman web sekaligus.

1. Menghubungkan CSS dengan HTML

Metode terbaik dan paling rapi untuk pemula adalah menggunakan External CSS. Kita menulis kode gaya di file terpisah bernama style.css, kemudian memanggilnya di dalam tag <head> di setiap halaman HTML yang kita miliki.

<link rel="stylesheet" href="style.css">

2. Aturan Dasar & Selector CSS

Kode CSS bekerja dengan cara memilih elemen HTML (menggunakan Selector) lalu memberikan nilai gaya baru padanya. Berikut adalah contoh sintaks dasar CSS yang paling sering digunakan:

/* Mengubah gaya seluruh tag paragraf di web */
p {
    color: #a0a0a0;     /* Warna teks abu-abu */
    font-size: 16px;    /* Ukuran teks */
    line-height: 1.6;   /* Jarak antar baris */
}

/* Mengubah gaya elemen berdasarkan Class */
.kartu-artikel {
    background-color: #111111;
    border-radius: 10px;
    padding: 20px;
}

Mengapa CSS Sangat Penting?

CSS tidak hanya membuat web terlihat indah, tetapi juga memengaruhi pengalaman pengguna (User Experience). Tata letak yang rapi, tombol dengan efek transisi yang interaktif saat didekati kursor, hingga penataan teks yang nyaman dibaca adalah hasil dari pengaturan CSS yang baik.

Setelah memahami struktur dasar HTML, menguasai CSS adalah langkah kedua paling seru dalam petualanganmu membuat website modern pertamamu!
