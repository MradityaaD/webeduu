Mengenal GitHub: Tempat Kolaborasi Developer

KOLABORASI Oleh: Tim WebEdu

Bayangkan kamu sedang mengerjakan proyek website bersama 3 orang temanmu. Jika kalian hanya membagikan file kode lewat WhatsApp atau Flashdisk, pasti akan sangat membingungkan ketika harus menggabungkan pekerjaan masing-masing. Di sinilah Git dan GitHub menjadi penyelamat para *developer*.

1. Git vs GitHub: Apa Bedanya?

Banyak pemula yang mengira keduanya adalah hal yang sama. Padahal mereka berbeda fungsi namun bekerja sama secara sempurna:

  • • Git: Adalah program *Version Control System* (Sistem Pengontrol Versi). Anggap saja ini sebagai mesin waktu. Jika kode webmu tiba-tiba error parah, kamu bisa memutar waktu dan mengembalikan kodemu ke versi sebelumnya yang masih berfungsi.
  • • GitHub: Adalah layanan *cloud* (seperti Google Drive) khusus untuk menyimpan kode-kode yang menggunakan Git. Di GitHub, kodemu aman tersimpan secara online dan siap dikolaborasikan bersama tim.

2. Perintah Dasar Wajib Tahu

Kamu biasanya akan menggunakan terminal (Command Prompt/CMD) atau terminal bawaan VS Code untuk menjalankan perintah Git. Berikut adalah siklus dasar mengirim kodingan dari laptopmu menuju ke GitHub:



// 2. Memberi nama/label pada perubahan tersebut (menyimpan versi)
git commit -m "Menambahkan halaman Detail Berita GitHub"

// 3. Mengirim / Mengunggah kode tersebut ke server GitHub
git push origin main

Kesimpulan Perjalananmu!

Mulai dari merangkai HTML, mempercantik dengan CSS, menghidupkannya lewat JavaScript, menyusun logika Backend dengan PHP, dan akhirnya menyimpannya di GitHub. Rangkaian pengetahuan ini adalah fondasi yang luar biasa solid bagi kamu yang ingin terjun sebagai Web Developer profesional.

Tetap semangat ngoding, jangan takut error karena error adalah cara komputer mengajarimu. Selamat berkarya!
